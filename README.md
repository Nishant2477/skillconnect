# SkillConnect

SkillConnect is a workspace containing the Node API and React client.

## Setup

1. Install workspace dependencies with `npm install`.
2. Copy `backend/.env.example` to `backend/.env` and set your local MongoDB URI, JWT secret, and Requesty API key.
3. Start both applications with `npm run dev`.

The API uses port 5000 by default. Vite selects an available frontend port.

Run `npm run build` to build the frontend.
